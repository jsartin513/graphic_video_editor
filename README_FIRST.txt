VIDEO MERGER — INSTALLATION
===========================

1. Check your Mac (Apple menu → About This Mac)
   • Apple chip (M1/M2/M3/M4) → use the arm64-fat DMG
   • Intel processor        → use the x64-fat DMG

2. Open the .dmg file

3. Drag "Video Merger" into Applications

4. Open Video Merger from Applications

That's it. The app includes ffmpeg — nothing else to install.
Requires macOS 10.15 or later.

If macOS says the app is damaged, the copy you downloaded was
not notarized. Ask for a new build, or see INSTALLATION_TROUBLESHOOTING.md.
